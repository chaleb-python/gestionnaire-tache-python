# 🐍 Gestionnaire de tâches Python

Mon premier projet Python : un gestionnaire de tâches simple réalisé dans le cadre de mon apprentissage de Python.

## 🎯 Fonctionnalités

- Ajouter une tâche
- Afficher les tâches
- Supprimer une tâche
- Quitter le programme

## 🛠️ Technologies utilisées

- Python

## 📚 Ce que j'ai appris

Grâce à ce projet, j'ai pratiqué :

- Les listes
- Les boucles `while` et `for`
- Les conditions `if`, `elif` et `else`
- Les fonctions intégrées comme `append()` et `pop()`
- La récupération des données avec `input()`

## ▶️ Utilisation

Lancer le fichier `main.py` avec Python, puis choisir une option dans le menu.
